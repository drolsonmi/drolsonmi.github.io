Below is the rubric for the classification project.

## Rubric
| Component      | Criteria                                                              | Points  | Score   |
| :------------- | :-------------------------------------------------------------------- | :-----: | :-----: |
| Preprocessing  | Data is loaded, cleaned, split, and scaled                            |         |         |
| Naive Bayes    | Naive Bayes classifier built correctly and confusion matrix displayed |         |         |
| kNN            | kNN model built correctly and confusion matrix displayed              |         |         |
| SVMs           | Support Vector Machine built correctly and confusion matrix displayed |         |         |
| Comparison     | Metrics are compared with visualizations and discussed                |         |         |
| Questions      | All answers are thoughtfully answered, demonstrating understanding    |         |         |
| **Total**      |                                                                       | __100__ | __0__ |

## Criteria
1. Preprocessing (20 points)
    - Data is loaded
    - Data is cleaned
    - Cross Validation used to split data into training and testing datasets
    - Feature Scaling applied
2. Naive Bayes (15 points)
    - Naive Bayes model is built correctly
    - Naive Bayes model is trained correctly
    - Naive Bayes model is tested, showing the confusion matrix
3. kNN (15 points)
    - kNN model is built correctly
    - kNN model is trained correctly
    - kNN model is tested, showing the confusion matrix
4. SVMs (15 points)
    - SVM model is built correctly
    - SVM model is trained correctly
    - SVM model is tested, showing the confusion matrix
5. Comparison of models (20 points)
    - Visualizations made to compare the model
    - Discussion of the comparison
6. Questions (15 points)
    - All 4 questions are given thoughtful responses, demonstrating understanding of classification concepts
